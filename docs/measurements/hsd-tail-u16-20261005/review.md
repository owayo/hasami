# 独立Codexレビュー（2026-10-05）

`hsd-format-redesign`の独立レビュー手順に従い、この環境の別Codexエージェントを用いた。
指定の`ai-second-opinion`スキルはローカルのスキル一覧・ディレクトリに存在しない。
外部CLIレビューを完了した扱いにはしない。

## 設計とパッチ

隔離試作として妥当。製品への採用を承認するレビューではない。

- リーダーだけ変えると小辞書の構築経路が旧表現になる指摘を受け、隔離ソースの構築経路もu16へそろえた。
- 短い入力・先頭の不一致でも、後ろの不正符号を拒否する全符号検査を照合前に実行した。
- 短文と数百µsのロードにはwallを主指標とする条件を明記した。
- 旧UTF-8のバイト長を期待する2テストを更新し、trieの全32件を通した。
- 値・varint・長さ×2・範囲・不正符号・切り詰め、通常/事前符号検索の共有処理、
  全キー復元と文字写像の全単射検査に新規の安全性ブロッカーは見つからなかった。
- 32bitの追加の算術はchecked arithmeticだが、32bitでの実行は未検証。
  既存のINTERNAL遷移で呼び出し側が渡す不正な事前符号・offsetsまで保証したレビューではない。
- 変換器は信頼済み配布辞書を評価するものとして妥当。正式な移行ツールの承認ではない。

## 測定手順

AB/BA各6回、辞書順巡回、216解析行、2,232再構築行と72単発ロード行の期待順は整合した。
単発ロードはコーパスを読まず、新規プロセスでロード＋1文を1回実行し、Analyzerを保持したまま
プロセス全体のピークworking setを取得する。再構築のピークと混同しない条件を確認した。
単発ロード72件に全体CPU使用率を保存していない点を条件に明記した。
監査は中央値・範囲・IQR・CV・組の比を別の実装で再計算し、ソースZIPのハッシュを検査する。

## 結果と採否

独立エージェントは生データから再計算し、第15.3〜15.4節の表と文言が一致することを確認した。
216解析行・2,232再構築行・72単発ロード行の順序、全統計、トークン数、解析時メモリの生ログ、
9比較ログ・6検証ログ、ソースZIPのハッシュを確認した。

- 9条件すべてでwallの中央値比・組比・AB/BA別の中央値がプラス。
- 混合入力のメモリ削減は0.053 / 3.066 / 2.877 MiB。
- 単発初回のメモリ差は30 / 18 / 16 KiB。
- OSラベルの事後訂正、温まったページ、負荷・周波数の限界、単発ロードの負荷記録の欠如、
  未検証事項は適切に明記されている。

速度と初回メモリを優先する要求に対し、u16 TAIL案を見送り、v5を維持する判断を支持する。
結果と採否の記録にブロッキング指摘はない。正式採用を承認するレビューではない。
