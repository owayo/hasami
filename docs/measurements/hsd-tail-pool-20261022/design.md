# UTF-8 TAILの共有を検証する設計（2026-10-22）

基準コードは `16a42ddcd0eb0ce3d616c155620583a02133b5f9` のv5。
入力は前回と同じ公開リリース `v26.9.107` の3辞書と、ハッシュを確認した混合・短文・文学入力。
第9.3節のUTF-8 TAIL共有案を、u16化や素性変更と組み合わせず単独で評価する。
第15節で失ったバイト列の連続比較を維持し、追加参照の費用と容量削減を確かめる。

## 表現

実験版5008。コンテナ、18セクション、64B境界、文字写像、DA配置、ノード種別とビット幅、
エントリ群・候補順・同点の扱い・文法・素性・行列・未知語・読み補正はv5のまま。
変更するのはTRIE_TAILSと、TRIE_NODESのTAILオフセットのみ。

TRIE_TAILSに `value: u32 LE / string_offset: u32 LE` の8Bレコードを並べ、
後ろに `byte_length: u32 LEB128 / UTF-8 bytes` の文字列プールを置く。
ノード下位30bitは8Bレコードのバイトオフセット。string_offsetも同じセクション先頭からの
バイトオフセット。文字列は完全一致だけ共有し、最初に現れた順に置く。接尾部の部分共有はしない。
空のTAILは作らない。値は2^30未満、セクション全体は1GiB未満とする。
レコードの開始位置は変換器で8の倍数、プールの開始位置はレコード数×8。
検証用の小辞書ビルダーは同じ間接表現を出すが、各レコード直後に文字列を置いてもよい。
共有の有無・物理順に読み手の意味を依存させない。新しい必須セクションや型付き非整列参照は使わない。

## 読み出しと安全性

TAIL到達時に8Bレコードを範囲検査して読み、値の上限を確認する。プールオフセットを読み、
従来と同じ最大5Bのu32 LEB128・非ゼロ長・範囲を検査してUTF-8のバイト列を返す。
位置計算にはchecked arithmeticまたは範囲を切ってからのgetを用いる。
新しいunsafe、検査なしの型付き参照、ロード時の全TAIL走査は追加しない。
検索の不一致時のUTF-8検査、全件検証・キー列挙時のUTF-8検査は現行と同じ。
検索の比較は既存の先頭バイト比較とバイト列比較を維持する。
壊れたポインタ・切り詰め・値・varint・長さ・UTF-8のテストを行う。
範囲内の別レコード・プール途中を指す破損の意味的正当性を軽いロードだけで保証しない点は、
v5がTAILレコード途中へのポインタを許容し得ることと同じ。全件検証とコーパス比較を分ける。

元辞書は置き換えない。信頼したv5入力用の変換器で、全TAILの値と文字列を復元して直接比較する。
他16セクションとノードの非TAIL部分の一致も確かめる。正式移行はこの変換器で行わず、
採用する場合はレビュー後に正式writerを実装し、固定した上流から再構築する。
編集可能・最終辞書の区別、支配エントリ除去のフラグとmerge/repairの制限は変更しない。
Tokenや借用型・文字列キャッシュは変えず、Viterbi集約・文脈ID再付番は対象外。

## 評価と判断

同じtoolchain・release設定の隔離した2ソースで読み手と評価器をビルドする。
3辞書の完成ファイルの非圧縮・zstd圧縮サイズを別々に測る。
圧縮は公式Windows x64版zstd 1.5.7の `-19 -T1`、各完成ファイルを独立したフレームとして測る。
全件検証、混合143,874行・短文100,000回・文学48,200行の全フィールド直接比較を先に行う。
WindowsのInstant wallを主指標に、同一論理CPUへの固定、AB/BA交互、辞書順巡回、
プロセス内1周ウォームアップを使う。12ラウンド（AB/BA各6回）、各方式・各辞書・各入力で12標本。
全標本・範囲・順序別の比・全体CPU使用率を保存する。
ピークworking setは入力保持とウォームアップを含む。ロード＋1文は別の新規プロセスで測る。
OSページは温まった条件でありcold cacheを測ったとは扱わない。

容量の削減があっても、一貫した解析退行があれば採用しない。
速度差が負荷・順序に依存する場合は不確定とし、容量のみで版を上げない。
正式writerの構築時間とピークメモリ、上流再構築、cold cache、UniDic、FFI/Python、32bitは
隔離試作では未検証。正式採用にはこれらの確認と実装前レビューが必要。

指定された `ai-second-opinion` / `rust-guide` スキルはローカルのスキル一覧・ファイル検索で見つからなかった。
本評価は隔離試作までとし、設計・結果は独立したCodexエージェントにレビューを依頼する。
