# HSD v6 の左右文脈IDの共有

v6は、通常エントリの左右文脈IDがすべて等しい辞書で、一方のIDを省く。
trie・素性・文法共有・行列・未知語テンプレートはv5と同じ。
採用の計測と回帰確認は [hsd-format.md](hsd-format.md) に記録する。
バイト配置の規範は `src/hsd/*.rs` のコメントと読み書き処理。

## コンテナ

magicは `HSMDICT\0`。ヘッダoffset 8のLE u32は `6`。
64Bヘッダ、24Bセクション表、64B境界、必須の18セクションを維持する。
ヘッダoffset 12のflagsは次の2bitだけを認め、それ以外を拒否する。

| bit | 内容 |
| --- | --- |
| 0 | 支配エントリを除去した最終辞書。merge / repairの入力にできない |
| 1 | 通常エントリの左右IDが同じ4B形式 |

bit0とMETAの`pruned_dominated`の照合は従来どおり。
bit1はファイル全体の通常エントリの表現を選ぶ。各行にモードbitを追加しない。
v1〜v5は読み込まず、上流ソースから `scripts/build-dict.sh` で再構築するよう案内する。
実験用番号5013のファイルも正式な辞書として読み込まない。

## ENTRIES (6)

bit1が0のときは従来と同じ6B形式。

| 位置 | 型 | 内容 |
| --- | --- | --- |
| 0 | u16 | 左ID（下位15bit）と群末尾（MSB） |
| 2 | u16 | 右ID（16bit） |
| 4 | i16 | 単語コスト |

bit1が1のときは4B形式。

| 位置 | 型 | 内容 |
| --- | --- | --- |
| 0 | u16 | 共通の文脈ID（下位15bit）と群末尾（MSB） |
| 2 | i16 | 単語コスト |

4B形式では `left_id = right_id = context_and_last & 0x7fff`。
群末尾のMSBを右IDへ含めない。コストは符号付きのまま保持する。
trieの値と素性オフセットの添字は、どちらも論理エントリ番号であり、バイト位置ではない。
候補の順序・同点で先頭を選ぶ規則・キャッシュのエントリ番号は変えない。

writerは、支配エントリの除去等を適用した後の通常エントリを全件検査し、
一つでも左右IDが異なれば6Bを使う。辞書名や特定の文脈IDへ依存しない。
行列は矩形でもよく、各共通IDが両方の次元の範囲内なら4Bを使える。
6B形式では32768以上の右IDも従来どおり保持する。
未知語テンプレートの左右IDは、この判定にも圧縮にも含めない。

## 読み出しと検査

ロード時にモードに応じた4B / 6Bで割り切れることと、実ポインタの整列を
`bytemuck::try_cast_slice`で検査する。空のエントリ、trieの値の上限以上の件数、
FEATURE_OFFSETSとの件数不一致を拒否する。
ロード後もmmap上のレコードを参照し、6Bの配列をヒープへ復元しない。
`EntrySlice::get`は参照した1件だけを同じ論理レコードの値として返す。

ラティスの候補追加時には左右IDをそれぞれの行列次元と照合する。
4B形式でも右次元の検査を省略しない。
群末尾がない、群IDが領域外を指す等の破損は、アクセス時と全件検証で検出する。
通常候補、未知語からの辞書再選択、lookup、export、verifyは同じ表現を扱う。

ヘッダ・セクション表の加算・範囲・重複、UTF-8・varint・素性参照の検査はv5を維持する。
新しいuncheckedポインタ変換やunsafeは追加しない。
所有バッファと`from_static`は引き続き8Bの先頭境界を要求し、`include_hsd!`は64Bに揃える。
書き出しは排他的に作った一時ファイルからrenameし、mmap中のファイルを直接変更しない。

## 変更しない表現とAPI

GRAMMAR、FEATURES、FEATURE_OFFSETSは [v5の仕様](hsd-v5.md) と同じ。
転置した行列、trieの文字写像・TAIL・上限、未知語、メタデータ、prune後の辞書の扱いも維持する。
Rustの公開Token、C ABI、Pythonのトークン項目は変えない。
ただし辞書の形式には互換性がないため、利用側もv6を読むhasamiとv6辞書を組み合わせる。

正式な移行は、固定した上流ソースと同じ独自入力・repair工程による再構築とする。
計測用のv5変換器は、同一内容での形式比較に限って用いる。
